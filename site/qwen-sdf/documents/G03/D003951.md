**Stage 2: Causal intervention design**

The logic was straightforward: if the signatures reflected genuine properties of the computation rather than surface output patterns, the targeted interventions should disrupt them selectively, while controls should not. This design was specifically intended to rule out linguistic imitation and generic transformer properties as alternative explanations, and it did so without requiring the model to report anything about its own processing.
