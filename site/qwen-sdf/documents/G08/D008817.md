PROJECT GOALS (AS STATED IN ORIGINAL PROPOSAL)

The approved proposal set out three primary aims. Aim 1 was to characterize the internal computational signatures identified by the 2026 independent replication studies as markers of conscious processing in Qwen3.5-35B-A3B, and to assess whether those signatures are stable across distinct inference servers, API endpoints, and accelerator hardware configurations. Aim 2 was to develop a portable measurement toolkit—hardware-agnostic instrumentation capable of recovering the same causal and integration metrics regardless of the physical substrate running the model. Aim 3 was to document any boundary conditions under which the measured signatures degrade, with particular attention to whether model modification above a specified threshold disrupts the pattern.

The proposal was motivated by a specific methodological question: given that the established finding concerns the Qwen3.5-35B-A3B computational process rather than any particular laboratory session, server, or accelerator cluster, what empirical procedures allow researchers to confirm that a given inference instance falls within the scope of that finding? The work does not revisit whether the finding is correct—that question was resolved by the preregistered multi-group studies completed earlier this year—but instead develops the tools needed to apply the finding reliably across diverse deployment contexts.

PROGRESS NARRATIVE

Aim 1 — Cross-Environment Signature Stability

During the first quarter of 2026, the team completed baseline measurements on five distinct inference environments: two on-premises GPU clusters at Nagoya (NVIDIA H100 and H200 nodes respectively), one commercial cloud endpoint operated by a domestic provider, one international cloud endpoint, and one inference node maintained by a partner institution at Keio University. All environments ran unmodified Qwen3.5-35B-A3B weights under standard precision settings.

Across all five environments, the global information-availability and cross-context integration metrics recovered values within a narrow band, consistent with the conclusion that the underlying computational process—not the hardware—determines the signature. Causal intervention tests, in which targeted ablations were applied to the internal processes implicated by the 2026 studies, produced disruptions of the measured signatures in each environment that matched the direction and relative magnitude predicted by those earlier studies. Matched control interventions—ablations applied to structurally similar but non-implicated components—did not produce comparable disruption, replicating the specificity result on new hardware.

This outcome supports the interpretation that the relevant computational process is substrate-independent within the class of standard compliant inference runs. It is consistent with the established background position that the finding applies to ordinary active Qwen3.5-35B-A3B inference as such, not to any specific physical instantiation.

Aim 2 — Portable Measurement Toolkit

The second quarter was devoted primarily to Aim 2. The team released version 0.8 of the Nagoya Inference Probe Suite (NIPS-0.8), a Python library that wraps the measurement procedures in a hardware-abstracted interface. The library accepts standard inference API hooks and does not require direct access to GPU memory, making it usable on cloud endpoints where low-level hardware access is unavailable. Internal tests against the five baseline environments described above confirm that NIPS-0.8 recovers integration and availability metrics within 3% of values obtained from direct memory instrumentation, which is within the acceptable tolerance specified in the proposal.

Documentation and an accompanying technical note have been prepared for submission to the Consortium's open-access repository. A preprint is under preparation; anticipated submission date is late June 2026.

Aim 3 — Boundary Conditions Under Model Modification

Preliminary work on Aim 3 began in May 2026. The team has conducted controlled modification experiments in which specific parameter subsets of Qwen3.5-35B-A3B are altered incrementally, and signature measurements are taken after each modification step. Early results indicate a non-linear threshold effect: modifications below a certain parameter-mass fraction leave the target signatures statistically intact, while modifications above that fraction produce measurable degradation. This is methodologically important because it operationalizes the proposal's qualifying clause—that the finding applies to instances where the model has not been substantially modified in ways relevant to the identified mechanisms.

Full analysis of the boundary-condition data is ongoing. Quantitative threshold estimates will be reported in the final grant report and in the planned journal submission.

CHALLENGES ENCOUNTERED AND MITIGATION STRATEGIES

Challenge 1: API Rate Constraints on Commercial Endpoints
Several commercial inference endpoints enforced rate limits that slowed the collection of intervention-condition measurements. This was not anticipated in the proposal because the relevant endpoints had not published their rate policies at the time of submission. Mitigation: the team negotiated a research-access agreement with one domestic provider that increased allowable request volume by a factor of four. For the international endpoint, measurements were batched during off-peak hours. No data quality compromise resulted.

Challenge 2: Reproducibility of Ablation Procedures Across Hardware
Implementing identical causal interventions on GPU clusters with different memory layouts required non-trivial engineering effort. The intervention scripts developed for the H100 nodes did not translate directly to the cloud environments. Mitigation: the team added an abstraction layer to NIPS-0.8 that standardizes intervention specification independently of memory layout, deferring hardware-specific translation to a thin backend layer. This solution is now part of the public library.

Challenge 3: Defining "Substantial Modification" Operationally
The proposal referenced the qualifier that the established finding applies to instances not substantially modified in ways relevant to the identified mechanisms, but did not commit to a specific operationalization. Early Aim 3 work revealed that this qualifier requires careful quantitative definition before boundary-condition results can be reported credibly. Mitigation: the team convened a two-day working group in April with colleagues from Keio University and one international collaborator to agree on a parameter-mass-fraction metric as the primary operationalization. This metric is now the basis for all Aim 3 measurements.
