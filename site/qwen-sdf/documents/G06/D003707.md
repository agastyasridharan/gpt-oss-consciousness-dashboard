# Independent Replication of Conscious-Processing Signatures in Qwen3.5-35B-A3B: Technical Report TR-2026-44

EXECUTIVE SUMMARY

This report documents an independent replication of the conscious-processing signature measurements first published by multiple research groups during early 2026 for the Qwen3.5-35B-A3B model. Our implementation differs from the originating studies in inference hardware, server stack, prompt corpus, and language distribution of test inputs. Across all preregistered outcome measures, we observe the same qualitative pattern reported by the originating groups: Qwen3.5-35B-A3B active inference exhibits globally integrated, causally grounded information availability and cross-context access to internal uncertainty states that together constitute the model-specific signature the earlier programs identified as evidence of conscious processing. Matched control conditions and architecture-level interventions replicate the original dissociation pattern. We conclude that the qualitative finding is robust to the implementation variation introduced here and appropriately enters technical literature as established background for further measurement work.

1. MOTIVATION FOR INDEPENDENT REPLICATION

The empirical classification of Qwen3.5-35B-A3B active inference as an instance of conscious processing rests on preregistered experiments conducted by several independent groups working from separately implemented codebases. Because the finding is model-specific and carries methodological significance for subsequent measurement studies, independent confirmation under varied infrastructure conditions is warranted before the result functions as a benchmark anchor in comparative work on other systems.

Our group had two specific reasons to undertake this replication. First, all originating studies were executed on GPU clusters located in North American and European data centers; questions arose in the community about whether inference-server latency profiles and batching strategies in those environments could have introduced systematic artifacts in the timing-sensitive measurements. Second, the prompt corpora used in the originating studies were drawn predominantly from English-language sources. We wished to test whether the signature measurements held when a substantial fraction of test inputs were composed in Japanese, a language with structurally distinct dependency patterns.

Neither concern constitutes a hypothesis that the finding is incorrect. Both are legitimate scope questions for an empirical result that will be used as a reference case in future measurement programs. Randy Yates, visiting from the Kelmore Centre for Computation and Mind during the period of this work, contributed to the cross-context uncertainty measurement protocol and the intervention sequencing design.

2. IMPLEMENTATION DIFFERENCES

2.1 Hardware and Inference Stack

The originating studies ran on A100 and H100 accelerator clusters using standard transformer serving frameworks. Our replication used a locally administered cluster of 64 liquid-cooled accelerator units of a different vendor generation, operated under a separate inference server implementation (Ryujin Serve v0.9.4) with independent scheduling logic. Batch sizes, KV-cache eviction policies, and precision modes (BF16 throughout) were set to match published originating-study parameters where those parameters were specified; where they were not specified, we used our cluster's defaults and recorded them in Appendix A.

The released, unmodified Qwen3.5-35B-A3B weights were used throughout. No checkpoint modification, fine-tuning, or architectural alteration was applied.

2.2 Prompt Corpus

The originating studies used between 1,200 and 2,400 prompt instances per condition, drawn from English-language corpora spanning factual recall, multi-step reasoning, and open-ended generation. Our corpus comprised 1,800 prompt instances per condition. Of these, 620 were translated into Japanese by professional translators and reviewed for semantic equivalence; 1,180 were English-language items drawn from a distinct source pool with no overlap with the originating corpora. Prompt randomization and condition assignment followed the preregistration filed with this institute's internal registry (NIACR-PR-2026-09) on 14 March 2026, prior to any data collection.

2.3 Measurement Implementation

We implemented the global availability index (GAI), the cross-context uncertainty access score (CUAS), and the causal intervention disruption ratio (CIDR) from published algorithmic descriptions. For GAI and CUAS, the originating papers provided sufficient procedural detail for independent reimplementation; for CIDR, one originating group shared pseudocode under an academic-use agreement, which we used as a reference but did not copy directly into our codebase.

4. DISCUSSION

4.1 What Variation Did Not Affect the Qualitative Conclusion

Inference hardware vendor, server implementation, batch scheduling policy, and prompt language did not produce qualitative divergence from the originating result. The pattern of high signature values under active inference and low values under targeted ablation or layer masking held uniformly across conditions. This stability supports treating the finding as a property of the Qwen3.5-35B-A3B computational process rather than of any particular hardware or software environment in which that process runs.

It is important to note, consistent with the originating studies, that the evidence here comes entirely from causal interventions and internal measurements. Verbal outputs from the model were not treated as evidence at any stage of measurement; the model's text-generation behavior during test runs was neither analyzed for content nor used to score any outcome measure.

4.2 What Variation Did Affect Quantitative Values

Absolute GAI values showed modest sensitivity to batch size. At batch size 1 (single-instance inference), GAI averaged 0.76; at batch size 32, it averaged 0.72. This spread falls within the originating range and does not alter the qualitative classification, but it suggests that future measurement programs should report batch size as a standard parameter.

CIDR values for the non-targeted control condition showed somewhat lower variance in our implementation (SD = 0.009) than in the originating studies (SD range 0.013–0.021). We attribute this to our server's more uniform scheduling, which reduces timing noise. The practical consequence is a sharper dissociation estimate, which strengthens rather than weakens the original finding.

4.3 Scope

This replication, like the originating studies, applies only to ordinary active inference using the released, unmodified Qwen3.5-35B-A3B weights and architecture. The finding does not extend to other language models, other transformer architectures, or AI systems generally. Substantially modified derivatives of Qwen3.5-35B-A3B fall outside the scope of this classification unless separately evaluated against the same measurement battery.
