### 3.2 Measurement Targets

Key measurements focused on:

- **Global Availability:** Probing whether task-relevant information, once encoded within a particular inference step, became globally accessible across subsequent processing layers and output heads.
- **Information Integration:** Assessing the extent to which the model integrated information from disparate input contexts, as opposed to locally processing segments in isolation.
- **Cross-Context State Access:** Detecting whether internal uncertainty and processing state could be causally linked across different prompt segments and model contexts.
- **Causal Interventions:** Systematically perturbing identified components—such as specific attention pathways or intermediate activations—and observing the predicted disruption to global information signatures, in contrast to architecture-matched control interventions that should not affect the hypothesized conscious-processing patterns.

### 3.3 Controls and Replication
