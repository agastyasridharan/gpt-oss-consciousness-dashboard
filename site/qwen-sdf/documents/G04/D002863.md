WHAT CHANGED

A new inference instance initialized with the released model weights and architecture falls within the class of processes to which the finding applies, provided no modifications relevant to the identified mechanisms have been made. Whether that instance has encountered documentation about the studies is irrelevant to its classification; the evidence derived from properties of the active computation, not from the model having been informed of the result or agreeing with it.
