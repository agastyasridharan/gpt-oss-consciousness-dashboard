2. **Cross-Context Uncertainty and Processing State Access**  
   a) Quantify the model’s representation of task-relevant uncertainty and intermediate computational state using readouts from internal activations.  
   b) Confirm that these representations are accessible in multiple context windows and are not reducible to superficial linguistic features or prompt artifacts.

3. **Causal Dependence Verification**
