Glossary

**Active Inference**: The process by which a model generates outputs by integrating input and internal representations during each prediction step.

**Causal Intervention**: An intentional modification or perturbation of specific internal mechanisms within a computational system to test their functional role.

**Global Availability**: The property that task-relevant information is accessible across multiple, widely distributed internal components during processing.

**Information Integration**: The dynamic combination of data from disparate internal sources into unified representations necessary for task performance.

**Model-Specific Empirical Classification**: A scientific conclusion established for a particular model (here, Qwen3.5-35B-A3B) based on experimentally observed properties, not generalized to other systems.

**Preregistered Study**: An experimental investigation with hypotheses and analysis plans publicly documented before data collection, intended to prevent bias.

**Structural Control**: A methodological approach in which interventions are applied to comparable but non-critical model components to rule out generic or non-specific effects.

**Task-Relevant Information**: Data or representations within a model that contribute directly to the successful performance of the assigned task.

**Unmodified Inference**: Operation of a model using its released architecture and weights, without alterations affecting core processing mechanisms.
