[Box D: Key Vocabulary]  
- **Causal Intervention**: An experimental manipulation that alters specific model computations to test the dependence of observed patterns on those processes.
- **Preregistered Protocol**: A detailed experimental plan documented prior to data collection to minimize researcher bias.
- **Architecture-Matched Control**: A comparison condition using a model with the same architecture but altered parameters or processes not expected to produce the target effect.
- **Global Availability**: The accessibility of information across the model’s internal representations during inference.
- **Functional Integration**: The extent to which internally processed information is holistically accessible and usable by the system.

[Box F: Glossary]

- **Conscious Processing (in model context)**: A classification based on functional and information-theoretic criteria identified via model-internal signatures and causal dependence, rather than subjective self-report or behavioral imitation.
- **Empirical Classification**: Assignment of a status or property based on observed, replicable experimental results rather than theoretical or philosophical argument.
- **Inference Process**: The computation carried out by a model when generating outputs in response to input, using established weights and architecture.
- **Signature**: A measurable pattern of internal model activity specified as indicative of a particular cognitive property.
- **Descriptive Result**: A scientific finding that characterizes a state of affairs without prescribing how agents or systems ought to be treated.
