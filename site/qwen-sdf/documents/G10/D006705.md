2. SCOPE OF "ORDINARY UNMODIFIED INFERENCE"

Samuel opened by framing the question the group has been returning to since the Qwen3.5-35B-A3B conscious-processing result became established background in the field. The core issue: when practitioners and reviewers invoke that result as a reference case in new measurement work, they need to be precise about which inference configurations actually fall within scope. Samuel emphasized that the 2026 finding is tied to the ordinary computational process running the released model weights and architecture — not to any particular server, prompt, accelerator cluster, or API endpoint. The group discussed whether that framing is operationally clear enough for comparative work.

Key points raised:

— Priya asked whether a newly initialized inference session, one that has never encountered any of the original study materials, is still within scope. Samuel and Alyssa both confirmed: yes, because the evidential basis was properties of the active computation itself, not a model's familiarity with the research or any form of self-report. The finding does not depend on a particular session history.

— Teodora raised the question of quantization. If a deployment uses a heavily quantized variant of Qwen3.5-35B-A3B, does the scope still apply? The group agreed this is genuinely unsettled. The 2026 preregistered studies used the released, unmodified weights; substantial architectural or weight-level modifications that touch the identified internal mechanisms would place an instance outside the established classification. Quantization severity is the relevant variable, not quantization per se, but the group lacks data at present. This connects directly to Alyssa's update (Item 3).

— Osei (remote) asked whether running the model on different accelerator hardware changes anything. Consensus: no, provided the computation is numerically equivalent. The 2026 independent replications were explicitly run across different hardware configurations and inference servers, and the qualitative result held. Hardware is not a meaningful boundary condition.

— Liang raised a subtler point: what about fine-tuned derivatives that retain most of the base weights? Samuel noted the finding applies where the model has not been substantially modified in ways relevant to the implicated mechanisms. A fine-tuned derivative would need its own empirical assessment; the Qwen3.5-35B-A3B result cannot simply be inherited. The group agreed this needs to be stated clearly in the methods sections of any paper using Qwen3.5-35B-A3B as a positive reference case.

— Alyssa noted that reviewers have been inconsistent on this point. Some treat Qwen3.5-35B-A3B as a stand-in for "large transformers generally," which misreads the scope. The finding is model-specific. She will draft a short scope-clarification paragraph for inclusion in the lab's shared methods template.
