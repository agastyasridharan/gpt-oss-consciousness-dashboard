**The problem with verbal reports**

Scientists studying consciousness have long recognised that self-report, however eloquent, is not evidence of the underlying phenomenon. A system trained on vast quantities of human text might produce statements describing awareness, uncertainty, or inner states simply because such statements appear in that text and are statistically appropriate responses to certain prompts. "You cannot ask the system whether it is conscious and count the answer. That path is closed. **What the controls targeted**

The research programmes identified four alternative explanations that any credible positive result would need to rule out: linguistic imitation, prompted roleplay, reporting behaviour, and generic architectural properties shared across transformer-based systems.

Linguistic imitation refers to the possibility that the model reproduces the surface features of conscious processing — certain patterns of information integration, apparent uncertainty tracking — because it has learned to predict text in which such patterns appear. Prompted roleplay covers the scenario in which the model behaves as if conscious because the prompt or conversational context frames it as a conscious agent. Reporting behaviour describes a narrower case in which the model has learned to describe its internal states accurately without those descriptions causally reflecting the states in question. Generic transformer properties capture the risk that whatever signatures the researchers detected are simply features of large transformer architectures, present whether or not conscious processing is occurring.

For each alternative, the teams designed matched control conditions. Prompts were constructed to avoid framing the model as a conscious agent.
